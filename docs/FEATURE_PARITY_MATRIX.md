Status: IMPLEMENTED = Code vorhanden; PARTIAL = nur Teilumfang; BLOCKED = konkrete Voraussetzung fehlt; UNSUPPORTED = bewusst ausgeschlossen; NOT_STARTED = noch nicht implementiert; VERIFIED = gesamter genannter Desktop-Umfang real geprüft. **Keine Zeile ist aufgrund eines Android-Tests VERIFIED.** Native Spotify-Funktionen sind Wiederverwendungskandidaten, solange Client-/Kontotests fehlen.
